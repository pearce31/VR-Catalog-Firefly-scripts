VR CATALOG

v1

A stereo VR catalog. Add sources, tap Enter VR, drop the phone in. Look to aim the reticle. Mouse: left-click opens, right-click / back-button goes back a level, wheel scrolls. No mouse: tap = open, long-press = back, or set a Dwell time below to select by holding your gaze.

Sources
Chaturbate proxy (optional)
Point this at your cb-proxy.js (e.g. http://127.0.0.1:8899/?url=). Blank = use public proxies.
Media proxy (Emby / Jellyfin over HTTPS)
For Emby/Jellyfin on self-signed HTTPS: run media-proxy.js and put its URL here. Blank = direct.
Player URL (APK → Edge)
In the APK, set this to the server that serves play.html so Plex opens in Edge. Blank = same site.
